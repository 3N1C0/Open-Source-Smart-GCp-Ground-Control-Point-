# PCB

Schematic and board layout for SmartGCP.

**Status:** not started. The current build is hand-wired from modules; see
[docs/wiring.md](../docs/wiring.md).

The board is intended to replace the jumper-wire build by carrying the ESP32,
the UM980 GNSS module and the microSD socket on one PCB. When work begins,
this directory will hold the design source files plus exported schematic PDF,
Gerbers and bill of materials.
