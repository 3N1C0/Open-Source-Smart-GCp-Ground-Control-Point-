# CAD

Mechanical design for the SmartGCP enclosure and target.

**Status:** a working model exists but the files have not been added to the
repository yet.

When they are added, this directory will hold:

- `source/`: editable CAD files in their native format
- `step/`: STEP exports for use in any CAD package
- `stl/`: print-ready meshes, with print settings noted here
